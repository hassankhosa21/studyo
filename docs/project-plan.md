# Studyo Project Plan

## Overview
6 core tools: PDF Merge, PDF Compress, Image Compressor, 
Citation Generator, Word Counter, GPA/CGPA Calculator.

## Target Users
Pakistani university students, school/college students, 
job applicants, teachers.

## Monetization
Google AdSense + Affiliate + Premium (Phase 2)

## Roadmap
- Week 1-6: MVP launch
- Month 2-4: Phase 2 (more tools, universities)
- Month 4-8: Phase 3 (accounts, premium, Play Store)
