# Studyo - Free Student Tools

Free web platform for students: PDF tools, image compressor, 
citation generator, word counter, GPA/CGPA calculator.

## Structure
- frontend/ → Next.js UI
- backend/  → API routes (Phase 2)
- database/ → Supabase schemas
- docs/     → Documentation

## Tech Stack
- Next.js + React + TypeScript
- Tailwind CSS
- pdf-lib, browser-image-compression
- Supabase (optional)
- Vercel hosting
