# Studyo Backend

Backend API for Studyo - Free Student Tools.

## Purpose

Phase 1 mein backend ki zaroorat nahi (saare tools browser mein chalte hain).
Ye folder Phase 2 ke liye ready hai, jahan hum ye services add karenge:

- PDF Compression (Ghostscript)
- URL/DOI se citation auto-fill
- User accounts (Supabase)
- CGPA history cloud save

## Tech Stack

- Node.js + Express
- TypeScript
- Ghostscript (Phase 2, PDF compression ke liye)
- Supabase (optional, database ke liye)
