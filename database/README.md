# Studyo Database

Database schemas and migrations for Studyo (Phase 2).

## Purpose

MVP mein database ki zaroorat nahi — saara data browser ke localStorage mein.
Ye folder Phase 2 ke liye ready hai, jahan hum ye features add karenge:

- User accounts (optional)
- CGPA history cloud save
- Feedback collection
- Saved citations

## Tech Stack

- **Supabase** (Postgres + Auth + Row Level Security)
- Free tier: 500 MB database, 50,000 monthly active users
